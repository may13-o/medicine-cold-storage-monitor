# UART Protocol (MCXC444 ↔ RW612)

**Link:** UART, 115200 baud, 8N1, 3.3 V logic. Binary, length-prefixed frames with CRC-8. Implemented in `firmware/common/protocol.c` and verified by `tests/host/test_protocol.c`.

## Frame format

```
 0      1      2      3 .. 3+len-1   3+len   4+len
+------+------+------+--------------+-------+------+
| 0xA5 | type | len  |   payload    | CRC8  | 0x5A |
+------+------+------+--------------+-------+------+
```

- `len` is at most 16.
- CRC-8 covers `type`, `len` and `payload`: polynomial `0x07`, init `0x00`, no reflection, no final XOR. Check value: CRC of ASCII `123456789` is `0xF4` (asserted in the tests).
- Multi-byte fields are **little-endian** and written byte by byte (no packed structs), so there are no unaligned accesses, which fault on Cortex-M0+.
- **Resync:** a partial frame is abandoned if more than 50 ms passes between bytes, and an illegal `len` resets the parser at once. This stops one corrupted length byte from swallowing the next good frame.

## Message types

| Type | Name | Direction | Payload |
|---|---|---|---|
| `0x01` | TELEMETRY | node → gateway | 15 bytes, below |
| `0x10` | CMD_TIME | gateway → node | `u32` UTC epoch. Node writes it to the RTC and clears the RTC fault |
| `0x11` | CMD_MUTE | gateway → node | none. Same as the local button |
| `0x12` | CMD_HB | gateway → node | none. Sent every 10 s |

Any valid frame from the gateway counts as a sign of life. If none arrives for 60 s, the node sets `FAULT_NO_GATEWAY` and the OLED shows `NET?`.

## Telemetry payload (15 bytes)

| Offset | Size | Field | Meaning |
|---|---|---|---|
| 0 | 4 | `seq` | Increments every frame. Gateway detects gaps; a step backwards means the node rebooted |
| 4 | 4 | `epoch` | UTC seconds from the RTC. `0` means time not valid |
| 8 | 2 | `temp_x100` | °C × 100, signed. Holds the last good value if the sensor has failed |
| 10 | 2 | `rh_x100` | %RH × 100, clamped to 0..10000 |
| 12 | 1 | `state` | `0` NORMAL, `1` WARNING, `2` ALARM |
| 13 | 1 | `fault` | Bitmask, below |
| 14 | 1 | `muted` | `1` if the buzzer is muted |

Example frame (seq 1042, epoch 1794096000, 4.45 °C, 61.20 %RH, NORMAL, no faults), generated by the code:

```
A5 01 0F 12 04 00 00 80 BB EF 6A BD 01 E8 17 00 00 00 D0 5A
```

## Fault bitmask

| Bit | Name | Meaning |
|---|---|---|
| 0 (`0x01`) | `FAULT_SENSOR` | SHT40 failed 3 reads in a row (NACK, timeout or bad sensor CRC) |
| 1 (`0x02`) | `FAULT_RTC` | RTC invalid: oscillator stopped, power lost, or no reply |
| 2 (`0x04`) | `FAULT_OLED` | Display not responding (non-critical) |
| 3 (`0x08`) | `FAULT_NO_GATEWAY` | No frame from the gateway for 60 s |

A sensor fault forces `state = ALARM`, because a dead sensor must not look like a healthy fridge.

## Gateway behaviour

1. Reject any frame with a bad CRC or illegal length. Count it (`parser.crc_errors`, `parser.resyncs`).
2. Track `seq`: gaps add to `missed_frames`, a backwards step adds to `node_restarts`.
3. **Timestamp:** use the node's RTC `epoch` when valid. If it is `0`, use the gateway's SNTP time and mark `ts_src = gateway`. If neither exists, mark `ts_src = none` and let the cloud use its receive time.
4. **Downsample:** the node sends every 10 s. The gateway queues one routine record per 30 s, plus a record immediately on any change of `state`, `fault` or `muted`.
5. **Store and forward:** records wait in a 2048-entry FIFO (about 17 hours at one record per 30 s, longer with state-change-only traffic). When full, the oldest NORMAL record is dropped first, so alarm history survives a long outage.
6. **Publish oldest first.** A record leaves the queue only after the publish is acknowledged. Records that waited more than 5 s are marked `"buffered": true`.
7. Send `CMD_HB` every 10 s, and `CMD_TIME` once SNTP has a time, then every 6 hours, and again within 10 s if the node reports an invalid RTC.

## Why binary, not ASCII

An earlier draft of this repo used a text frame (`$MED,...*CRC`) for easy terminal debugging. Binary was chosen instead because it is fixed-size, cheap to parse on a Cortex-M0+ with no `sscanf`, and has proper resync. For bring-up, log decoded frames to a debug UART or add a small host script that prints them.
